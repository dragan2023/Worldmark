设计关键词

集印驱动文献感节气与诗意可核验的严谨当代国潮

色板 · TOKENS

paper / #F6F0E1 宣纸底 ink / #26221C 玄墨（正文与描边） cinnabar / #B5382A 朱砂（印章与主按钮） indigo / #33565B 黛青（辅助与文学类） gold / #A9812F 鎏金（来源注脚与点缀）

字体系统

  • 标题：Noto Serif SC 900，大字距（.06–.16em）立风骨
  • 诗句 / 批注：Ma Shan Zheng 手写体，只作点睛
  • 正文：Noto Sans SC，行高 2.0，两端对齐仿书页

签名组件

  • 印章体系：门类用色对应印色（游戏朱砂 / 文学黛青 / 影视鎏金）
  • 集印册：4×4 印格，已钤朱印 / 未钤虚格
  • 楹联信息卡：地址 / 行至 / 开放 / 图谱 对仗排布
  • 山水横幅：SVG 层峦 + 朱日 + 云纹分隔线
  • 钤印动效：落印回弹 + 印泥晕影

数据映射 · 真实能力

  • GET /search?q= 全站检索
  • /literature · /games · /screen 三扇门类
  • GET /landmarks/{id} 三段式详情 + 来源核验
  • POST /api/v1/itineraries/finalize 行路生成
  • /maps/{module} 会员静态地图
  • /intake 一键入库投条目

适用与取舍

  • 适合：文学与古建 IP、博物馆/文旅联动、徽章收集运营
  • 优势：与「已核验」的严谨气质天然契合，老年/年轻用户都不排斥
  • 风险：装饰密度高，需控制每屏一个焦点；影视/潮流 IP 气质稍弱

数据说明：地标与文案取自 data/seed/landmarks_verified.csv 与 landmark_content.json；「集印 / 钤印」为提案功能（后端暂无打卡接口），其余入口均对应现有路由。地图为静态参考，不提供实时导航。
