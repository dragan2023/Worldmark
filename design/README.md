## 交互点

- 移动版内含 4 屏（**发现 / 地标详情 / 行程 / 我的**），通过底部标签栏或屏幕切换按钮切换
- Web 版为站点导航 + 同样 4 个页面视图（1240px 版式，≤980px 自动折叠为单列）
- 方案 A：AR 扫描打卡动效（扫描线 → 印章）、弹幕条、充能进度条
- 方案 B：钤印落章动效、集印册 4×4 印格、楹联信息卡
- 方案 C：票根可勾选（完成贴纸弹出）、打卡闪光动效、拍立得 hover 回正
- 方案 D：收藏 ♡ 变色、行程完成态、编号索引行

## 数据与边界（重要）

- 地标、地址、文案取自真实种子数据：`data/seed/landmarks_verified.csv`、`data/seed/landmark_content.json`
- 带「提案」标记的功能（AR/钤印/贴纸打卡、徽章等级、弹幕、深色模式）为设计建议，**当前后端尚未提供**
- 其余入口均映射现有路由：`/search`、`/literature | /games | /screen`、`/landmarks/{id}`、`/maps/{module}`、`/itineraries/*`、`/intake`、导出 HTML/DOCX/XLSX
- 共创入口已统一为**应用内「一键入库」**（`/intake`，登录后用一句话提交候选地标，AI 联网核实并生成条目，管理员审核发布后署名）；原型中的「Fork 仓库 + 条目 CSV + PR」文案已同步改写，仓库不再接收共创 PR
- 遵守产品既有边界：地图为静态参考、不提供实时导航；目录检索与导出免费
- 预览中的打卡数/距离/等级等为演示占位
