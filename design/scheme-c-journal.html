色板 · TOKENS

字体系统

  • 正文：Noto Sans SC，稳重但不拘谨
  • 点缀：ZCOOL KuaiLe（中文手写）+ Caveat（英文批注）
  • 规则：手写体只用于「人的话」——批注、便签、贴纸

签名组件

  • 拍立得卡：±2° 随机旋转 + 胶带固定，hover 回正
  • 票根时间线：撕票虚线 + 圆形缺口 + 勾选贴纸弹出
  • 便签计划：图钉便签承载「本周小计划」
  • 气泡批注：社区攻略以「人的话」呈现
  • 明信片共创：把「一句话一键入库」翻译成「寄明信片」

数据映射 · 真实能力

  • GET /search?q= 全站检索
  • /literature · /games · /screen 三类目录
  • GET /landmarks/{id} 详情 + 来源核验
  • POST /api/v1/itineraries/finalize 行程生成
  • 导出 HTML / DOCX / XLSX
  • /intake 共创（明信片隐喻）

适用与取舍

  • 适合：轻旅行/周末游、女性向与社交分享场景、UGC 运营
  • 优势：与「拍照出片」内容天然耦合，传播性强
  • 风险：装饰元素多，正式感弱；信息密集页（表单/表格）需收敛为素纸样式
