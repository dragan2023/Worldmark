# 共创贡献规范

## 1. 提交方式

访问 `/contribute` 填写共创者署名、作品、地标、详细地址、三段式地标简介和至少一个可访问来源。提交后系统创建候选条目，状态为 `candidate`；候选内容不会出现在公开目录、导出或地图中。

## 2. 署名与身份

每次提交都会写入 `landmark_contributions`：

1. `contributor_name`：必填的公开署名，审核发布后显示在地标详情页。
2. `contributor_user_id`：可为空。提交者携带有效登录令牌或站内登录 Cookie 时自动记录；后续开放共创角色、修改权限和个人贡献页时以该字段作为身份关联。
3. `landmark_id`：指向本次提交产生的候选地标，因此可准确追踪“谁提交了哪一条”。

未登录提交的署名属于自我声明，不等同于已验证身份；审核人员可以通过来源与后续账号绑定进行核验。

## 3. 审核与公开

管理员通过既有审核接口核验候选条目，只有变为 `verified` 后才能单独发布。发布后的详情页显示共创者姓名；被拒或仍在候选状态的贡献记录仅由管理员在 `GET /api/v1/admin/contributions` 查看。

## 4. 数据边界

不要填写联系方式、住址、证件信息或其他不必要个人信息。公开署名请使用愿意被显示的名字或昵称。每条简介必须使用“在作品中的重要地位”“主要出现的情节”“现实地标介绍”三段式原创内容，并提供可访问来源链接。
