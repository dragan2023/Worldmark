# 来源分级与审核准则

## 1. 来源优先级

1. 官方景区、博物馆、文旅主管部门和政府公开页面。
2. 作品版权方、制作方、出版方、发行方的公开页面。
3. 权威媒体、出版社和可信机构的公开报道。
4. 公开地图、百科作为地址交叉验证。
5. 社交媒体只作线索，不能单独支撑公开发布。

## 2. 审核方式

每个来源必须写清所支持的声明范围：作品关联、地理位置、交通信息或简介。审核人以搜索 API 的引用信息和公开可见页面进行人工判断、手工录入结论；系统不读取或抽取目标网页正文。

## 3. 决策标准

- `verified`：地址与作品关联说明清晰，存在至少一条合格来源，且简介为原创表达。
- `rejected`：来源不足、地址不明确、作品关联不成立、内容版权存在风险，或记录重复。
- `candidate`：仅用于等待人工审核，禁止对外查询与发布。
