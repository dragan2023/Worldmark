# 05 — 最终验证与运营准备

## 1. 摘要

- 优先级：P0（收尾验收）
- 预计工作量：1–2 人日
- 直接依赖：02、03、04 全部完成
- 阶段目标：端到端演练整个共创闭环，确认文件封锁与审核机器人在真实 GitHub 环境生效；补齐文档与运营口径；按用户确认，私有阶段完成内部演练，公开共创测试时再切换仓库属性。

## 2. 前置阅读

1. 02 提示词包、03 机器人、04 流水线与共创者名单页面的全部产物。
2. `docs/共创贡献规范.md`、`README.md`、`docs/上线前数据检查清单.md`。

## 3. 任务详情

### 3.1 端到端演练（真实 GitHub，私有仓库内完成）

用测试 GitHub 账号（受邀为仓库协作者）按以下链路完整走一遍：

1. 在私有仓库内建测试分支 → 克隆 → 创建 `.venv` 并安装依赖 → 粘贴 `01_共创条目添加提示词.md`（在 Codex / Claude Code / WorkBuddy / Qoder 中至少实测两种）→ AI 智能体生成条目 → 本地校验 → 提交、推送 → 开 PR。
2. 观察机器人：越界尝试被拦截；合法条目校验通过；错误留言可修复后复查转绿；留言含 PR 作者 GitHub 用户名。
3. 维护者合入 → 04 发布流水线把条目并入种子并更新 `contributors.json` → 维护者在测试库运行 `seed_initial_landmarks.py` → 应用详情页出现该地标并显示 GitHub 用户名署名，`/contributors` 页面与 `GET /api/v1/contributors` 显示该用户名。
4. 产出《演练记录》存入 `docs/共创提示词包/演练记录.md`，记录遇到的问题与修复方式。

### 3.2 仓库可见性切换（用户已确认：测试共创时再改属性）

1. 私有仓库内演练通过后，由维护者在 GitHub 仓库 Settings 把仓库转为 public。
2. 转 public 后补充验证一次 fork 流程：测试账号 fork → 粘贴提示词 → 开 PR → 机器人审查 → 合入，确认外部共创者路径可用。
3. 转 public 前复查 `docs/隐私与数据保留说明.md` 与 `.env.example`，确认无密钥、无私有测试资料入库（`测试证据/`、`.workbuddy/` 已在 `.gitignore`）。

### 3.3 回归验证

1. `.venv\Scripts\python.exe -m pytest` 全绿，既有网页 `/contribute` 提交路径不受影响。
2. 数据质量检查：`.venv\Scripts\python.exe -m app.scripts.check_data_quality` 通过。

### 3.4 文档与运营准备

1. `README.md` 增加「如何参与共创」小节：网页提交与 Harness PR 两种方式、提示词包入口、署名规则（GitHub 用户名）、共创者名单页面 `/contributors`、审核与合入说明；文档列表加入 `/contributors` 与提示词包说明。
2. `docs/共创贡献规范.md` 完成 PR 共创章节的最终校对。
3. 明确运营口径：机器人只做确定性把关，不做内容审查；人工审核由维护者执行；争议条目走既有审核准则。
4. 更新 `docs/上线前数据检查清单.md`：entries 目录已清空/归档、种子去重、共创者名单与署名完整、`/contributors` 可访问、已发布地标可查询。

## 4. 精确文件范围

1. 修改：`README.md`、`docs/共创贡献规范.md`、`docs/上线前数据检查清单.md`。
2. 新增：`docs/共创提示词包/演练记录.md`（真实演练后）。
3. 仓库设置（非代码文件）：转 public（按 3.2 时机执行）。

## 5. 禁止修改与风险红线

1. 演练必须使用测试账号/测试分支，不得在正式分支制造噪音提交。
2. 不为了演示而绕过机器人检查或分支保护。
3. 演练结束按规则清理测试数据（归档或正式保留），不留脏数据在 entries 目录。
4. 转 public 前必须完成密钥与私有资料复查，避免泄露。

## 6. 验收标准

- [ ] 私有仓库内端到端演练完整跑通：协作者分支 → 提示词 → AI 智能体生成条目 → PR → 机器人 → 维护者合入 → 入库 → 详情页显示署名 → `/contributors` 显示用户名。
- [ ] 越界/违规 PR 在真实仓库被机器人拦截且无法合入。
- [ ] 转 public 后 fork 流程验证一次通过。
- [ ] `.venv\Scripts\python.exe -m pytest` 与 `check_data_quality` 全绿。
- [ ] `README.md` 与 `docs/共创贡献规范.md` 包含完整的共创入口、署名规则与名单页面说明。
