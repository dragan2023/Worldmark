# 美团酒旅官方 Skill 接入说明

## 配置

在项目根目录 `.env` 配置官方 Skill Token：

```dotenv
MEITUAN_HT_TOKEN=你的美团酒旅Token
```

`MEITUAN_TRAVEL_TOKEN` 仅为历史本地配置兼容项；请迁移到 `MEITUAN_HT_TOKEN`。Token 只由服务端短生命周期子进程读取，不会写入用户目录配置、数据库、日志或浏览器响应。

## 运行前置条件

需要 Node.js 18+ 与 `npx`。行程预览通过官方命令契约调用：

```text
npx --yes @meituan-travel/ht-ai@latest query --query <完整旅行需求> --origin-query <完整旅行需求> --channel meituan-developer --city <目的城市> -o json
```

首次调用会下载官方包；官方服务通常需要 1–2 分钟。该项目不调用假定存在的美团 REST 接口。

## 行程行为

1. 用户选择必去 IP 地标并填写日期、出发地、人数、预算和偏好。
2. 服务端将完整需求一次性发送给美团酒旅官方 Skill，并完整展示官方建议。
3. IP 地标仍由本地已发布数据集约束；生成可编辑日程时不会自动把酒店、交通、门票或餐饮订单、动态价格写入计划。
4. 用户需要在美团官方链接或其他渠道自行确认具体供给；确认后的项目可在后续编辑中写入行程。
5. Token 失效、超时、`npx` 不可用或官方服务失败时，页面会说明原因并降级为仅含已选 IP 地标的基础日程。

## 故障处理

- `exit 3`：检查 `MEITUAN_HT_TOKEN` 是否有效。
- npm 缓存权限错误：确认当前服务账户有 npm 缓存目录的读写权限，或预先由部署流程安装官方 `@meituan-travel/ht-ai` 包。
- 超时：美团官方 Skill 的单次请求可能耗时 1–2 分钟；请稍后重试，不会自动改用非官方 HTTP 接口。
- `未返回有效 JSON`：官方 Skill 输出格式异常，系统不会解析或写入该响应，改用安全降级。
