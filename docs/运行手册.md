# 运行手册

## 1. 本地环境

项目只使用根目录 `.venv` 中的 Python。首次安装依赖后，将 `.env.example` 复制为 `.env`，按需填写数据库和外部服务配置。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

开发地址为 `http://127.0.0.1:8000`，健康检查为 `/health/live`。

## 2. 外部服务开关

- `BAIDU_AI_SEARCH_API_KEY`：仅供管理员候选发现使用；搜索结果不自动发布。
- `AMAP_WEB_SERVICE_API_KEY`：供高级行程中的 POI、地理编码和路线参考使用；当前基础服务调用采用高德 Web 服务 v3 POI、v3 地理编码和 v5 路线接口。
- `MEITUAN_HT_TOKEN`：供美团酒旅官方 `@meituan-travel/ht-ai` Skill 使用；`MEITUAN_TRAVEL_TOKEN` 仅为本地历史配置兼容项。不发送假定存在的美团 REST 请求。

外部服务不可用时，不得阻塞已发布地标目录、免费导出、静态地图和本地确定性行程功能；界面应明确提示参考信息暂不可用。

## 3. 验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File .\scripts\verify_mvp.ps1
```

第二条命令使用临时数据库，不会升级或改写 `.env` 中配置的开发数据库。

## 4. 范围边界

当前版本不实现支付、订单、收款、第三方登录或实时导航。高德、美团和搜索信息均为生成或审核时参考，出行前仍需向官方渠道确认。
