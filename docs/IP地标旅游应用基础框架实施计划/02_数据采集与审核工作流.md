# 02 — 数据采集与审核工作流

## 3. 任务详情

### 3.1 接入搜索引擎 API，并建立候选数据台账和来源分级

新增 `app/integrations/search/baidu_web_search.py`、`app/services/search_discovery.py`、`data/templates/landmark_candidate_template.csv`、`docs/数据采集规范.md` 与 `docs/来源分级与审核准则.md`。首期采用百度智能云“百度搜索”官方 API 获取搜索候选，密钥仅从 `BAIDU_AI_SEARCH_API_KEY` 环境变量读取。调用使用 `search_source=baidu_search_v2`、网页资源类型和安全搜索；该接口不传 LLM `model`。禁止对结果 URL 发起二次抓取。该服务商实现必须遵循 `SearchProvider` 协议，保证未来可以在不改业务逻辑的前提下替换。

搜索调用以预定义查询模板生成，例如：`"{作品名}" 取景地 官方`、`"{作品名}" {城市} 文旅`、`"{地标名}" 地址 官方`。每次调用保存查询模板、实际查询、百度 `request_id`、`references` 中的标题/URL/摘要、调用时间、状态与额度计数；候选台账再包含 `ip_type`、作品名、别名、地标名、国家/省/市、完整地址、候选坐标、关联说明、交通文字、来源 URL、发布者、检索日期、授权/使用备注、录入人、审核状态。

来源优先级依次为：官方景区/博物馆/文旅主管部门；作品版权方、制作方、出版方或发行方；权威媒体/出版社；公开地图和百科作为地址交叉验证；社交媒体仅作线索，不能单独支撑发布。每条来源写明它支持的具体声明（作品关联、位置、交通或简介），不能笼统标为“已验证”。人工审核以搜索结果提供的标题、URL、摘要和公开可见页面为依据进行人工判断与手工录入，不把页面正文复制、解析或自动入库。

### 3.2 实现受控导入和审核后台

新增 `app/services/import_landmarks.py`、`app/services/review.py`、`app/api/admin/imports.py`、`app/api/admin/reviews.py`、`app/web/admin.py`。首版只接受管理员上传符合模板的 CSV；导入进入 `candidate`，逐行返回校验错误，不允许静默丢行。

审核操作必须记录审核人、审核时间、结论、理由和所依据来源。只有全部必填地理字段有效、至少有一条合格来源、坐标位于合理范围且作品关联说明清晰的记录才可转为 `verified`；发布必须是独立动作。对被拒记录保留原因，避免重复收集。

### 3.3 完成首批三模块种子内容

通过搜索 API 和人工复核各录入至少 3 个文学 IP、3 个游戏 IP、3 个影视 IP；每个 IP 至少 1 处已发布地标。以《黑神话：悟空》相关山西古建和《狂飙》相关江门地点作为候选线索时，必须以官方文旅/景区或制作方公开页面再次核验，不能只依据营销文章或用户评论。

输出 `data/seed/landmarks_verified.csv`，只放最小演示集与来源 URL；如来源条款不适合将其文字复制到仓库，CSV 仅保存原创摘要和链接。用导入接口创建数据，而不是绕过审核直接写库。

### 3.4 增加数据质量检测

新增 `app/services/data_quality.py` 和 `tests/services/test_data_quality.py`。每次导入或发布前检查：重复作品+地标、缺失国家/省/市、无来源、无审核、经纬度越界、交通文字中缺少信息日期、已发布但关联作品非发布状态。以命令 `python -m app.scripts.check_data_quality` 输出可修复问题和记录标识。

## 5. 禁止修改与风险红线

1. 不部署或调用无人值守的全网爬虫，不抓取、下载、解析搜索结果所指向网页，不绕过访问限制，也不把搜索引擎摘要或模型生成的总结当作事实来源。
2. 不把受版权保护的原文摘录、剧照、游戏资产导入种子数据。
3. 不以“坐标看起来合理”代替作品关联的来源核验。
4. 不让普通用户调用导入、审核或发布接口。

## 6. 验收标准

- [ ] 百度搜索 API 调用可按预定义查询模板完成并保存 `request_id`、引用和额度计数，且测试证明应用不会向搜索结果 URL 发起网页请求。
- [ ] CSV 模板、来源分级和审核准则能让非开发人员独立完成一次候选录入。
- [ ] 任何导入行都可追溯到来源 URL、检索日期和录入人；审核结果含审核人、时间和理由。
- [ ] 文学、游戏、影视各至少 3 个 IP 和对应地标通过审核并发布。
- [ ] 缺来源、无效坐标、地理字段不完整、重复记录均会被拦截或标记，且有自动化测试。
- [ ] 公开接口无法读取 `candidate` 或 `rejected` 记录。
