# 05 — 高级会员个性化行程

## 1. 摘要

- 优先级：P1
- 预计工作量：5–8 人日
- 直接依赖：03 三类地标目录与免费服务；推荐同时等待 04 完成以复用路线资料
- 阶段目标：为高级会员生成基于已发布数据的、可编辑保存的个性化旅游计划草案，而非虚构实时可执行的导航方案。

## 3. 任务详情

### 3.1 定义最小偏好与行程模型

新增 `app/models/itinerary.py`、`app/schemas/itinerary.py`。表单仅收集生成所需数据：目标作品/类型、目的地国家/省/市、出行日期范围、可用天数、每日时长、同行方式、步行偏好、预算档位、必去/不去地标和自由文本需求。提交前向用户说明用途与保存期限。

行程保存 `input_snapshot`、所用地标 ID 清单、模型/提示模板版本、生成时间、结构化每日安排、用户编辑版本与状态。不要把生成内容仅存成一段不可验证的富文本。

### 3.2 构建“约束优先”的生成服务

新增 `app/services/itinerary_planner.py`、`app/services/llm_client.py`、`app/services/itinerary_validator.py`、`app/integrations/amap_web_service.py` 与 `app/integrations/meituan_travel_mcp.py`。高德使用 `AMAP_WEB_SERVICE_API_KEY` 调用官方 Web 服务的 POI、地理编码与路径规划能力；美团酒旅使用 `MEITUAN_TRAVEL_TOKEN` 通过官方 `mttravel` MCP/CLI 接入，不实现假定存在的美团旅行 REST 请求体。两种外部服务都必须可关闭、可超时失败，并返回来源与查询时间。

流程必须是：

1. 由服务端根据筛选条件取回已发布且已核验的候选地标；
2. 用确定性规则过滤日期、地点、每日时长和用户排除项；
3. 仅把允许的地标事实、交通文字和免责声明作为模型上下文；
4. 要求模型返回符合 Pydantic JSON Schema 的每日计划；
5. 校验所有地标 ID 均来自候选集、每日天数/时长符合约束、没有未证实的门票/营业/交通承诺；
6. 校验失败时重试一次受限修复，否则给出不生成该部分的明确原因。

高德仅补充候选地标的 POI 标识、地点间距离和预计时长，结果标为“生成时参考”；美团仅补充酒店、门票、餐饮或机酒候选，保留来源链接与原始价格文字，不把库存、价格、营业状态或实时交通当作承诺。所有格式化输出从校验后的结构化行程生成：先提供网页/自包含 HTML、DOCX 与 XLSX；PDF 留给后续独立导出能力，不把 HTML 或模型富文本作为唯一存档。

提示词要求模型把不确定信息标为“出行前请向官方确认”，禁止捏造营业时间、票价、实时交通和不存在的作品关联。先实现一个确定性模拟生成器用于本地测试；生产模型提供商通过适配器注入。

### 3.3 提供高级会员表单、结果和编辑

新增 `app/api/itineraries.py`、`app/web/itineraries.py`、`app/templates/itineraries/*.html`。`premium` 专属接口包括创建、查看、编辑、删除自己的行程；`free`/`lite` 返回 403。结果按天展示地点、建议时段、地址、交通说明、选择理由、数据日期和总免责声明，用户可手工调整顺序、删除站点并保存新版本。

生成任务以数据库状态 `queued/running/succeeded/failed` 管理，浏览器使用短轮询读取状态；首期不需要消息队列。限制单账号每天 5 次成功生成、每次最多 7 天、每天最多 6 个地点，避免 API 成本失控。

### 3.4 隐私、安全和质量测试

记录调用耗时、候选数量、验证结果和成本估计，不记录完整自由文本提示或第三方原始响应。实现账户数据删除时一并删除其行程和偏好；管理员只能看聚合运行指标，不能浏览用户行程内容。测试覆盖越权访问、候选外地标幻觉、JSON 不合规、约束冲突、速率限制、编辑版本和删除流程。

## 5. 禁止修改与风险红线

1. 不向模型发送未发布内容、内部审核备注、用户密码或不必要身份信息。
2. 不把模型输出直接展示或保存为最终事实；必须经过候选集和结构校验。
3. 不承诺票价、营业、预约余量、天气、实时交通或安全状况。
4. 不实现订单、收款或任何资金处理；高级会员角色仅用于验证功能权限与使用额度。

## 6. 验收标准

- [ ] 仅高级会员可创建、查看、编辑、删除自己的行程；服务端授权测试通过。
- [ ] 每份计划的地点均来自已发布、已核验候选集，且可追溯生成输入和版本。
- [ ] 无法生成时页面给出具体、可理解的原因，而非虚构行程。
- [ ] 每日 5 次、最多 7 天和每天最多 6 地点的限制生效并有测试。
- [ ] 删除账户数据会删除关联偏好和行程；日志不包含完整敏感提示内容。
