# 03 — 三类地标目录与免费服务

## 1. 摘要

- 优先级：P0
- 预计工作量：5–7 人日
- 直接依赖：01、02
- 阶段目标：交付统一但可按文学/游戏/影视进入的目录体验，并向所有用户提供可导出的文字型地标清单。

## 2. 前置阅读

1. `docs/IP地标旅游应用基础框架实施计划/01_项目基线与内容模型.md` 中的模型、权限矩阵和目录结构。
2. `docs/IP地标旅游应用基础框架实施计划/02_数据采集与审核工作流.md` 中的发布条件与种子数据。
3. `app/models/ip_work.py`、`app/models/landmark.py`、`app/models/location.py`、`app/services/entitlements.py`。

## 3. 任务详情

### 3.1 提供三模块入口与统一筛选契约

新增 `app/api/landmarks.py`、`app/services/landmark_catalog.py`、`app/web/catalog.py`、`app/templates/catalog/*.html`。三模块入口分别是 `/literature`、`/games`、`/screen`，内部共用 `/api/v1/landmarks`。

筛选参数固定如下，所有组合使用 AND 关系：

```http
GET /api/v1/landmarks?ip_type=game&work=黑神话悟空&country=CN&province=山西省&city=大同市&page=1&page_size=20
```

`work` 同时匹配规范作品名和别名；`country` 传 ISO 代码；省、市使用精确匹配；查询只返回已发布地标。页面把 IP 名称筛选和地域三级联动展示为同一筛选表单，切换模块时保留地域条件但重置不适用的作品条件。

### 3.2 构建目录、详情和空状态

目录卡片显示作品类型、作品名、地标名、国家/省/市、原创简介摘要、数据更新时间；详情页显示完整详细地址、交通路线文字说明、来源链接和适用的免责声明。公共页面不展示经纬度、地图瓦片或路线线段。

对三种无结果分别给出明确状态：该作品暂无已发布地点、该地域暂无该类地标、组合条件无匹配；不可把候选记录拿来填充空结果。移动端优先，筛选区、列表、导出按钮应在 360px 宽度正常可用。

### 3.3 实现免费导出

新增 `app/services/export_landmarks.py`、`app/api/exports.py`。为当前有效筛选结果提供 CSV 和 XLSX；两种格式字段一致：作品类型、作品名、地标名、国家、省、市、详细地址、简介、交通文字、来源链接、数据更新时间。文件名包含模块与生成日期，例如 `game-landmarks-2026-08-10.xlsx`。

导出复用目录查询服务，不能再写一套未加发布状态过滤的 SQL。接口限制单次 1,000 行，超过限制时要求缩小筛选范围；记录匿名/账号导出事件和结果数量，不记录用户的精确地址或不必要个人信息。

### 3.4 完成检索和导出测试

为别名匹配、跨模块隔离、国家/省/市组合、分页、候选状态隐藏、CSV 字段和 XLSX 内容编写 API/服务测试。浏览器端至少覆盖筛选提交、无结果和导出入口的端到端冒烟测试。

## 4. 精确文件范围

1. 新增：`app/api/landmarks.py`、`app/api/exports.py`、`app/services/landmark_catalog.py`、`app/services/export_landmarks.py`。
2. 新增：`app/web/catalog.py`、`app/templates/catalog/index.html`、`app/templates/catalog/detail.html`、`app/static/css/catalog.css`、`app/static/js/catalog-filters.js`。
3. 新增：`tests/api/test_landmarks.py`、`tests/api/test_exports.py`、`tests/services/test_landmark_catalog.py`、`tests/e2e/test_catalog_smoke.py`。
4. 必要时新增：`alembic/versions/0003_catalog_indexes.py`，只建立已发布查询、作品别名和地域组合所需索引。

## 5. 禁止修改与风险红线

1. 不向免费接口泄露精确坐标、内部审核记录、编辑人或未发布来源备注。
2. 不把“按地域”降级为页面前端筛选；API 与导出必须使用同一后端过滤条件。
3. 不因资料不全而省略来源链接、数据更新时间或免责声明。
4. 不在本阶段开放地图点位、路线图或个性化行程能力。

## 6. 验收标准

- [ ] 文学、游戏、影视三个入口均能独立浏览，并复用同一筛选和详情契约。
- [ ] 用户可按书名/游戏名/影视剧名及国家、省、市的任意有效组合筛选。
- [ ] 免费/未登录用户能导出当前筛选范围内的 CSV 与 XLSX，内容只含已发布记录。
- [ ] 导出字段完整、编码正确、受 1,000 行上限保护；无匹配时不生成空白误导文件。
- [ ] 目录、详情、筛选和导出测试全部通过，移动端冒烟测试可用。
