# 04 — 轻量级会员地图与线路

## 1. 摘要

- 优先级：P1
- 预计工作量：4–6 人日
- 直接依赖：03 三类地标目录与免费服务
- 阶段目标：向轻量级及高级会员展示已发布地标的静态地图点位和人工审核的推荐游览线路，同时正确拦截免费用户。

## 2. 前置阅读

1. `docs/IP地标旅游应用基础框架实施计划/00_计划索引.md` 中的权益矩阵与地图红线。
2. `docs/IP地标旅游应用基础框架实施计划/01_项目基线与内容模型.md` 中的 `routes`、`route_stops` 和权益服务。
3. `docs/IP地标旅游应用基础框架实施计划/03_三类地标目录与免费服务.md` 中的筛选契约。
4. 所选地图供应商的最新官方许可、配额、署名和缓存政策；接入前必须复核，不以本文档替代服务条款。

## 3. 任务详情

### 3.1 增加受保护的地图数据接口

新增 `app/api/maps.py`、`app/services/map_data.py`，暴露 `/api/v1/maps/landmarks` 与 `/api/v1/routes/{route_id}`。接口通过 `EntitlementService.require("static_map")` 和 `require("static_route")` 校验；未登录或免费用户返回统一 403 权益错误码和升级页地址。

地图接口接受与目录一致的 `ip_type`、`work`、`country`、`province`、`city` 参数，且只返回已发布、已审核、经纬度存在的地点。响应仅含渲染所需的 `id`、名称、类别、经纬度、详情链接和更新时间，禁止携带后台审核注释。

### 3.2 实现静态点位地图

新增 `app/templates/catalog/map.html`、`app/static/js/landmark-map.js`、`app/static/css/map.css`。使用 Leaflet 渲染点位、聚合密集标记和点击信息卡；地图状态由 URL 筛选参数驱动，方便分享同一检索结果。地图只显示服务端已授权数据，不在前端包中嵌入供应商私钥。

页面明确标注“静态参考地图，非实时导航”，并在底部按供应商要求署名。地图瓦片 URL 来自 `MAP_TILE_URL` 环境变量，开发和生产环境分别配置。

### 3.3 建立人工编辑的推荐线路

新增 `app/api/admin/routes.py`、`app/services/route_builder.py`、`app/templates/routes/detail.html`。管理员以同一作品或同一城市的已发布地标创建线路，维护有序停靠点、建议停留时间、文字说明和总时长。首版线路是静态序列：连线只表达推荐访问顺序，不调用实时路径规划，也不宣称真实行车距离。

线路详情展示每站的地址、交通文字、建议停留、来源更新时间和免责声明；若某停靠点下线，整条线路自动标为不可发布，直至编辑替换或移除该点。

### 3.4 补齐授权、泄露和地图测试

覆盖 free/lite/premium 的 API 与页面访问、过滤后点位数量、无坐标记录隐藏、下线停靠点、地图供应商配置缺失和路线顺序。使用浏览器冒烟测试确认免费用户无法从 HTML、网络请求或页面源代码得到受保护点位坐标。

## 4. 精确文件范围

1. 新增：`app/api/maps.py`、`app/api/admin/routes.py`、`app/services/map_data.py`、`app/services/route_builder.py`。
2. 新增：`app/web/maps.py`、`app/web/routes.py`、`app/templates/catalog/map.html`、`app/templates/routes/detail.html`、`app/templates/admin/routes.html`。
3. 新增：`app/static/js/landmark-map.js`、`app/static/css/map.css`、`tests/api/test_maps.py`、`tests/api/test_routes.py`、`tests/e2e/test_membership_map_access.py`。
4. 按实际表设计新增：`alembic/versions/0004_route_publication_rules.py`。

## 5. 禁止修改与风险红线

1. 不把地图权限仅做成 CSS 隐藏或前端路由拦截。
2. 不接入实时导航、实时交通、用户轨迹采集或离线瓦片缓存。
3. 不绕过供应商许可抓取地图瓦片，也不在浏览器端暴露服务端密钥。
4. 不将自动连线伪装成经过人工验证的真实路线。

## 6. 验收标准

- [ ] `lite` 与 `premium` 用户能按三类模块和地域条件查看静态地图点位；`free` 与匿名用户被可靠拒绝。
- [ ] 地图、API 与页面源码均不会向无权用户泄露受保护坐标。
- [ ] 管理员可建立、预览、发布静态推荐线路；线路停靠点有确定顺序和文字说明。
- [ ] 下线地点会阻止关联线路继续发布。
- [ ] 地图署名、免责声明、配置缺失处理和权限测试均满足验收。
