# 03 — 相册与媒体可靠性改造

## 1. 摘要

优先级 P1；预计 3–4 日；直接依赖 01、02。目标：相册稳定绑定地标，暂存与正式图片访问边界明确，上传和提交可验证、可恢复。对应 B08–B10、R05。

### 1.1 前置阅读

`app/services/landmark_albums.py`、`app/services/landmark_album_editor.py`、`app/api/album.py`、`app/web/album.py`、`app/web/catalog.py`、`app/api/admin.py`、`app/main.py`、`app/static/js/album-editor.js`、`app/static/js/content_editor.js`、`scripts/download_commons_album_images.py`、`data/contributions/landmark_albums/README.md`、相册 service/API 测试。真实 manifest 只读取必要结构与统计，不批量修改。

## 2. 任务详情

### 2.1 稳定标识与完整迁移

默认采用本地数据库稳定 landmark_id 绑定 manifest，如 albums["landmark:123"]；保留当前文件资源与许可字段，不引入云存储或第二套永久索引。若确认存在跨独立数据库搬运需求，再评估 UUID，不能预防性增加。

新增 `scripts/migrate_album_keys.py`：默认只读 dry-run，输出旧键→地标 ID 映射、缺失和多义条目；只在唯一匹配时自动迁移。多义同名不得猜测归属。正式 apply 需用户授权并先备份，采用可核对的迁移清单，失败不破坏原文件。

修改 get_photos/first_photo_url/editor_snapshot/submit 及所有调用方；类型与名称仅用于展示，不作主键。完成迁移后删除旧键读取路径；如真实历史数据尚未获授权迁移，保留明确的临时兼容条件并报告，不能删真实图片。

### 2.2 保护暂存和未发布资源

移除 /staging/landmark-albums 对整个目录的匿名 StaticFiles 挂载。保留图片预览 URL 时改成鉴权路由，只允许指定地标贡献者或管理员读取白名单图片，禁止 _meta.json、任意路径和其他用户文件。预览响应 private/no-store。

正式图片也应检查所属地标公开资格，避免待审图片通过旧 URL 绕过审核。公开目录与编辑预览区分访问判断；同一资源多人引用时先核对真实引用再清理。不要向浏览器返回磁盘路径。

### 2.3 真实图片校验和上传边界

先审查现有依赖是否包含可用图片解码器；若无，增加成熟维护的 Pillow 及明确支持格式，验证当前版本对 WebP/AVIF 的能力。不能手写仅凭魔数的完整解码器。

上传分块读取并在超过 8 MiB 时停止，保留现有单次 12 张上限；校验实际格式、可解码性和合理像素上限。伪 MIME、截断文件、超大像素图片应拒绝。将测试中的假 PNG 替换为真实极小图片，保留独立损坏样本。元数据保留作者、来源、许可；不把 AI 找图自动等同于已授权发布。

### 2.4 提交一致性与失败恢复

使用明确的相册版本/内容摘要做乐观冲突检查，旧编辑会话返回 409。对共享 manifest 的读改写使用覆盖多进程的互斥机制；先检查已有依赖，缺失时选择成熟文件锁库，不用只在单线程有效的锁充当完整保护。

提交顺序：校验全部资源→准备新文件和唯一临时 manifest→在锁内验证版本并切换索引→成功后处理旧资源。失败时保留原相册可读，并回滚本次准备的文件；单纯 os.replace 不能保证所有文件操作一致。禁止解析失败后静默用空 manifest 覆盖原内容。

新增故障注入测试：磁盘写失败、重名提交、同相册并发、不同相册并发、重复暂存图片。无引用资源清理先 dry-run，不自动删用户暂存和回收站历史。

## 3. 禁止事项与风险

不按名称猜测同名相册归属；不删除许可、署名或用户文件；不把隔离演练授权扩展为正式媒体迁移；不同时长期维护两套 manifest。受正式迁移授权阻塞时，完成新实现、迁移工具和合成数据验证后交接。

## 4. 验收标准

- [ ] 改名不丢图；同类型同名不同地标互不串图。
- [ ] 迁移 dry-run 可识别多义项；失败不改原索引，图片及元数据计数可核对。
- [ ] 匿名、非贡献者不可读暂存图片或 _meta.json；合法编辑者仍可预览。
- [ ] 待审核/已撤回图片不能绕过内容访问规则直接公开。
- [ ] 真实格式校验、8 MiB/批量/像素边界有效。
- [ ] 写失败和并发测试后相册与文件一致；旧会话不会覆盖新提交。
- [ ] 老键调用方、被替代静态挂载和无效测试实现已清理。
