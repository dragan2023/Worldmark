### 3.1 目录导出的纠正结论

README 声称提供 /api/v1/exports/landmarks.xlsx，但实际请求为 404；app/main.py 没有目录导出路由，现有目录页面测试要求不出现导出入口。LandmarkExportService 仍存在，直接调用服务导出的“=1+1”文本被 openpyxl 写为公式类型 f。

这是“无路由残留实现及文档不一致”，不能称为已确认公开导出漏洞。在线行程导出有独立实现，必须单独检查外部文本单元格，保留系统主动生成的 SUM 公式。默认清理目录导出的过时承诺和无效代码；是否重新推出属于额外产品决定。

## 4. 产品与体验判断

现有桌面风格统一，模板和 CSS 足以继续演进；首页大横幅占据主要首屏，搜索靠后，完整地标卡片落在较下方。首页“查看全部”只跳文学；详情缺直接加入行程的主要动作；相册编辑链接对所有访客显示；登录成功总回首页；缺个人贡献状态入口。以上基于截图与源码，不是用户访谈结论。

建议以“搜索作品/地点→查看可信详情→选择必去点→生成并编辑行程”为主流程，共创作为次流程；展示真实角色能做的动作、审核状态、来源更新时间和未标价项目。保留现有视觉识别，提高内容与操作的密度。

尚未实测：手机/平板布局、屏幕阅读器、真实 PostgreSQL、新环境完整安装、大规模并发、第三方真实返回与付费链路、真实数据质量和图片授权完整性。方案将这些列为实施验收，不冒充本轮结果。
