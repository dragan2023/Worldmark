## 1.2 总体原则

保留 FastAPI、SQLAlchemy、Alembic、Jinja2、原生 CSS/JS、Leaflet。优先利用现有模块与依赖；不引入 SPA、微服务、通用插件框架。保留“山河印迹”的宣纸、朱砂、黛青设计语言，以内容可读、行动明确为目标。

权限默认沿用现有 `app/services/permissions.py`：公开浏览；登录可贡献；level1/admin 可管理自己的行程；仅贡献者本人及管理员可编辑指定地标。修 bug 不扩大访问权限。

## 2. 范围与红线

1. 不执行 Git、部署、真实付费服务调用或子代理；不修改正式数据库、真实图片、密钥及贡献资料。
2. 测试只用隔离数据库、合成数据和服务替身。正式数据迁移另需明确授权。
3. 不新增支付、订单、实时导航、AR、社交动态或用户追踪。
4. 已被本次替代的入口、配置、重复实现及其无效文档必须同步清理；历史迁移、用户资料和有调用方的实现不得误删。
5. 目录导出目前无在线路由，不能依据过时 README 自动恢复；行程 HTML/DOCX/XLSX 导出必须保留。
6. 外部调用失败必须可见，不能把不完整结果伪装成已确认计划、真实价格或已核实地点。
