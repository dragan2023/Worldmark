# 06 — 性能治理与最终验证

## 1. 摘要

优先级 P1/P2；预计 2–3 日；直接依赖 01–05。目标：消除已知查询浪费，建立关键行为回归、运行诊断与可复现交付。性能量测贯穿开发，最终验收在功能完成后进行。

### 1.1 前置阅读

`app/api/admin.py`、`app/api/admin_users.py`、`app/services/landmark_catalog.py`、`app/services/map_data.py`、`app/db/session.py`、`app/main.py`、`app/core/rate_limit.py`、`app/integrations/meituan_travel_mcp.py`、`tests/conftest.py`、`tests/e2e/`、`scripts/verify_mvp.ps1`、`README.md`、`docs/用户系统开发计划.md`、`docs/隐私与数据保留说明.md`。

## 2. 任务详情

### 2.1 查询与资源优化

管理员列表以数据库 COUNT 求总数，用户列表 COUNT 必须带同样筛选条件，membership 使用批量预加载，避免 N+1。目录筛选项用 distinct 投影，保留完整地区组合，不能仅按城市名去重导致同名跨地区混淆。

先测 100/1000/10000 条合成数据的查询次数、耗时、响应体大小和浏览器渲染；根据证据增加实际查询需要的索引，检查 PostgreSQL 执行计划。地图全量点位超过合理容量时采用视口/筛选范围与服务端上限并明确告知结果范围，不静默截断，也不默认引入搜索引擎或聚类库。

相册读取缓存必须在提交后失效；不加入缺少收益证据的跨请求缓存。上传图片缩略图复用阶段 03 的解码能力，保留原图与许可，不把重复大图送到所有卡片。

### 2.2 外部依赖与运行可观测性

美团适配器固定已验证包版本，记录安装步骤、Node/npx 前提和返回契约测试；不现场猜版本，不把最新版自动下载作为请求逻辑。HTTP 客户端按真实复用需求管理生命周期，保持超时与脱敏错误信息。

增加请求标识、状态、耗时、provider 名、降级原因和调用次数等最小日志；不记录 key、token、Authorization、密码或完整用户正文。现有 /health/live 保持存活语义，新增 /health/ready 用轻量数据库连接与迁移就绪检查，不访问收费接口、不在健康响应泄露配置。

登录限速先修复过期键清理并测试 Retry-After；单进程部署写清边界。仅在实际多进程/多实例需求确认后使用共享限速存储，不为未来假设引入 Redis。

### 2.3 真正的浏览器回归与离线保障

保留现有 API/服务测试。tests/e2e 当前使用 TestClient，应准确命名/说明；新增 `tests/browser/` 的真实浏览器冒烟，优先使用现有可用工具，若需自动化依赖则只增加测试依赖，不装入生产运行环境。

覆盖首页搜索、地图输入、登录返回、贡献、相册预览/提交、基础行程生成/编辑/导出与权限异常。测试数据库从迁移构建；关键外部服务用替身，使用测试专用网络阻断避免无密钥时仍调用公共地理编码。独立开放本地测试服务，不连正式库。

服务端性能建议验收目标：在固定本机配置与 1000 条合成数据下，公开目录/详情/API 热态 p95 ≤500ms，连续请求至少 30 次；记录 SQL 数量和机器环境。若达不到先定位瓶颈，不能伪造数值。浏览器截图和耗时将字体/瓦片等第三方请求单独标注。

### 2.4 文档与废弃实现清理

README 按实际角色、规划模式、密码算法、迁移和端口更新；旧用户系统计划加历史说明并链接当前方案，不能继续把已完成功能写为“完全没有”。贡献规范与重审行为、相册资源边界一致。

目录导出默认按当前无路由行为收敛：核查脚本/动态入口/外部契约后删除无调用 LandmarkExportService、仅服务它的配置/上下文与过时宣传；不要误删行程使用的 export-feedback.js。涉及历史 export_events 模型/表时核查审计保留约定，不直接删除数据。

scripts/verify_mvp.ps1 的数据质量检查需带已知有效与无效合成样本，不能只在空库扫描零条就宣称内容可靠。清理自身临时进程和文件只针对已核实属于本轮的内容，保留测试证据和用户资料。

## 3. 禁止事项与风险

不拿测试通过数量替代行为覆盖；不报告未测的 PostgreSQL、移动端或第三方服务“已通过”；不无依据全站重构；不通过删有效测试掩盖失败；不自动运行正式迁移或真实付费联调。未解决的外部依赖列出复现命令与所需输入。

## 4. 验收标准

- [ ] 六阶段缺陷清单逐项有测试或浏览器证据，无未处理 P0/P1。
- [ ] 完整 pytest 在隔离环境通过；新增迁移测试不借 create_all 绕过迁移。
- [ ] 真实浏览器关键流程通过，控制台无应用异常；手机和平板证据齐全。
- [ ] 用户列表筛选总数正确，无逐用户 membership 查询；地标 COUNT 不全量加载实体。
- [ ] 性能报告包含数据量、环境、样本数、p95、查询次数，达成目标或写明具体瓶颈。
- [ ] live/ready 区分正确；上游故障日志可定位且不含秘密。
- [ ] README、示例、测试和有效入口一致；保留旧实现有具体调用方或迁移条件。
- [ ] 交付包含改动文件、清理范围、验证命令/结果和真实限制；未授权操作仍未执行。
