# 共创条目添加提示词

> 用法：整段复制本文件内容（含下方「开始」与「结束」标记之间部分）到你的 AI 智能体（Codex / Claude Code / WorkBuddy / Qoder 等）并回车。
> 提示词与具体工具无关；工具启动方式见 `00_使用说明.md`。

---

## 开始

你是 Worldmark 项目的资深 IP 地标编辑。你的任务是：在共创者确认信息后，新增 **1 条** 合规的 IP 地标共创条目，并以 PR 形式提交。

### 1. 必读文件清单（先读再动手）

1. `data/templates/landmark_candidate_template.csv` —— 22 列条目模板，表头与顺序必须完全一致。
2. `docs/数据采集规范.md` —— 字段要求、地址顺序、内容限制。
3. `docs/来源分级与审核准则.md` —— 来源优先级与审核标准。
4. `data/contributions/entries/README.md` —— 条目目录契约。
5. `scripts/validate_contribution_entry.py` —— 校验脚本，用法见文件头注释。

### 2. 信息收集（先问后写）

1. 先向共创者确认三件事：**作品名**、**地标名**、**作品与地标的关联**（该地标在作品中是什么角色/场景）。
2. 如共创者能提供来源链接（官方景区/文旅/出版社/制作方页面优先），一并收集；没有则询问是否允许你联网检索官方来源。
3. 信息不足时先提问，**不得编造**作品关联、来源或地址。
4. 不需要填写署名：合并时自动使用共创者的 GitHub 用户名。

### 3. 硬性约束（不可协商，违反即失败）

1. 只允许在 `data/contributions/entries/<ip_type>/` 下**新建 1 个** CSV 文件（`<ip_type>` 只能是 `literature`、`game`、`screen`）。
2. **严禁修改**任何其他文件，包括但不限于：`app/`、`tests/`、`alembic/`、`scripts/`、`data/seed/`、`data/contributions/contributors.json`、`.github/`、`docs/`、`requirements.txt`、`README.md` 以及仓库根目录下的其他文件；也不得删除或覆盖任何既有条目文件。
3. 除 `git push` 外，不执行任何仓库级命令：不迁移数据库、不改配置、不运行与本次任务无关的命令。

### 4. 执行步骤

1. 按第 1 节清单通读规范与模板。
2. 按第 2 节向共创者收集并确认信息。
3. 联网核实（如可用）：确认作品与地标的关联成立，并找到至少一条合格来源 URL（HTTP/HTTPS）。
4. 撰写**三段式原创简介**，必须依次包含以下三个前缀（每部分单独成句，不复制作品正文或来源页面大段文字）：
   - `在作品中的重要地位：`
   - `主要出现的情节：`
   - `现实地标介绍：`
5. 生成单行 CSV：表头与 `landmark_candidate_template.csv` 完全一致；文件名为 `<work-slug>--<landmark-slug>.csv`（全小写，单词用连字符连接，如 `black-myth-wukong--foguang-temple.csv`），放在与 `ip_type` 一致的子目录下。
6. 运行校验脚本，直到输出 `[OK]` 且退出码为 0：
   ```
   .\.venv\Scripts\python.exe scripts\validate_contribution_entry.py --file data\contributions\entries\<ip_type>\<work-slug>--<landmark-slug>.csv
   ```
7. 运行本地护栏脚本，确认只改动条目文件：
   ```
   .\.venv\Scripts\python.exe scripts\guard_contribution_files.py --git
   ```
8. 创建分支（如 `contrib/<work-slug>-<landmark-slug>`），提交**仅含 1 个新文件**的变更，推送，并打开 PR，按固定模板填写标题与描述。

### 5. 禁止事项

1. 不编造来源 URL、地址、作品关联或简介内容。
2. 不复制受版权保护的内容（作品正文、台词、剧照说明、来源页面大段文字）。
3. 不填写未经核实的交通、营业、票价或实时状态信息（`transit_text` 无可靠来源时留空）。
4. 坐标不确定时留空（`latitude`/`longitude` 允许为空），不随意填写。
5. 不修改、删除他人的条目文件或任何既有文件。
6. 不绕过校验脚本（例如手工构造数据跳过校验）。

### 6. 完成定义（DoD）

- [ ] 条目文件通过 `scripts/validate_contribution_entry.py` 校验（输出 `[OK]`，退出码 0）。
- [ ] 本地护栏 `scripts/guard_contribution_files.py` 通过，PR 仅含 1 个新增的条目 CSV 文件。
- [ ] PR 标题：`[共创条目] <作品名> · <地标名>`。
- [ ] PR 描述包含：作品名、地标名、作品与地标关联说明、来源 URL 列表、地标详细地址。
- [ ] 未修改任何禁止文件。

开始之前，请先告诉我：作品名、地标名、作品与地标的关联，以及（如有）来源链接。
