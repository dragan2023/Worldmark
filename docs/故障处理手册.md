# 故障处理手册

## 1. 高德 Web 服务

1. 先确认控制台中使用的是 Web 服务 Key，并检查基础 LBS、基础搜索服务的当日配额与 QPS。
2. POI 搜索使用 `v3/place/text`，城市筛选使用 `city` 与 `citylimit=true`；不要将基础搜索接到 v5 POI 接口。
3. 地理编码使用 `v3/geocode/geo`；步行路线使用 `v5/direction/walking` 并请求 `show_fields=cost`，否则路线时长可能缺失。
4. 记录 HTTP 状态、`status`、`info`、`infocode`、返回数量和耗时；日志中绝不记录 Key 或完整请求 URL。
5. 当接口限流、超时或没有结果时，保留已有详细地址和免责声明，不编造坐标、路线时长或 POI 匹配关系。

## 2. 百度搜索

1. 确认 `BAIDU_AI_SEARCH_API_KEY` 与每日额度。
2. 仅允许管理员候选发现接口调用；失败时返回可理解错误，不自动发布候选。
3. 复核搜索结果来源、关联事实和版权后，才进入审核流程。

## 3. 美团酒旅官方 Skill

1. 确认 `MEITUAN_HT_TOKEN` 有效，且 Node.js 18+、`npx` 可用。
2. 仅使用官方 `@meituan-travel/ht-ai` CLI 调用；不能退化为伪造的美团 REST 请求。
3. `exit 3` 表示 Token 无效或未配置；npm 缓存权限、网络超时或无效 JSON 都会显示明确提示并降级为基础 IP 地标行程。
4. 报价、库存、营业与预约只作查询时参考，调用失败或数据过期时提示用户到官方渠道确认。

## 4. 导出或数据库失败

1. 导出失败先通过 `pytest -q` 验证 HTML、DOCX、XLSX 导出回归测试。
2. 数据库迁移失败时，先在临时数据库运行 `scripts/verify_mvp.ps1`，确认失败的迁移版本与错误信息。
3. 未确认数据库备份和目标范围前，不执行删除、回滚或覆盖操作。


## 美团酒旅官方 Skill

详见第 3 节。官方查询由 `npx @meituan-travel/ht-ai@latest` 执行。
