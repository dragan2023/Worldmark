# 隐私与数据保留说明

## 1. 收集范围

个性化行程仅保存生成所需的目的地、日期、每日时长、同行方式、步行偏好、预算档位、用户备注、候选地标 ID、已选地标 ID 和结构化结果。不要在自由文本中输入身份证件、支付信息、精确实时位置或其他不必要敏感信息。

## 2. 外部服务数据

高德、美团和百度搜索只接收完成相应功能所需的查询词、地名或坐标。密钥存放于本地 `.env` 或部署环境变量中；日志、导出文件和错误响应不得包含密钥、访问令牌或完整第三方原始响应。

## 3. 保留与删除

行程在用户账户存在期间用于查看、编辑和导出。删除账户时，应一并删除关联的会员记录、行程、行程日程和站点；数据模型中的外键级联关系用于支持这一操作。运营日志只保留聚合的调用结果和耗时，不保留完整自由文本或第三方原始响应。

## 4. 用户可见提示

所有行程、地图和导出内容均提示：交通、票价、营业、预约、天气和安全信息需在出行前向官方渠道确认。
